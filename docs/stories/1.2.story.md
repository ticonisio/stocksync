## Story
**As a** lojista,
**I want** criar conta e logar com email e senha,
**so that** eu possa acessar o StockSync com segurança.

## Acceptance Criteria
1. Usuário pode se registrar com nome, email e senha via `/register`
2. Senha armazenada com hash bcrypt (salt rounds = 12)
3. Usuário pode logar com email/senha via `/login`
4. Login bem-sucedido redireciona para `/dashboard`
5. Credenciais inválidas exibem mensagem de erro clara no formulário
6. NextAuth.js Credentials provider configurado e funcional em `src/lib/auth.ts`
7. Sessão persistida via JWT em cookie HTTP-only seguro (expiração 30 dias)
8. Rota `/dashboard` protegida — não autenticados redirecionados para `/login`

### Auth Configuration (`src/lib/auth.ts`)
[Source: `docs/architecture.md` Section 11.4]
```typescript
import { NextAuthOptions } from 'next-auth';
import CredentialsProvider from 'next-auth/providers/credentials';
// GoogleProvider importado na Story 1.3
import { PrismaAdapter } from '@auth/prisma-adapter';
import { prisma } from '@/lib/prisma';
import bcrypt from 'bcryptjs';

export const authOptions: NextAuthOptions = {
  adapter: PrismaAdapter(prisma),
  session: { strategy: 'jwt' },
  providers: [
    CredentialsProvider({
      name: 'credentials',
      credentials: {
        email: { label: 'Email', type: 'email' },
        password: { label: 'Password', type: 'password' },
      },
      async authorize(credentials) {
        if (!credentials?.email || !credentials.password) return null;
        const user = await prisma.user.findUnique({ where: { email: credentials.email } });
        if (!user?.passwordHash) return null;
        const isValid = await bcrypt.compare(credentials.password, user.passwordHash);
        if (!isValid) return null;
        return { id: user.id, email: user.email, name: user.name };
      },
    }),
    // GoogleProvider — Story 1.3
  ],
  callbacks: {
    jwt({ token, user }) {
      if (user) token.id = user.id;
      return token;
    },
    session({ session, token }) {
      if (token.id) session.user.id = token.id as string;
      return session;
    },
  },
  pages: { signIn: '/login' },
};
```

### Registration Endpoint (`src/app/api/auth/register/route.ts`)
[Source: `docs/architecture.md` Section 6.6 + PRD FR1]
```typescript
import { NextRequest, NextResponse } from 'next/server';
import { prisma } from '@/lib/prisma';
import bcrypt from 'bcryptjs';
import { z } from 'zod';

const schema = z.object({
  name: z.string().min(1),
  email: z.string().email(),
  password: z.string().min(8),
});

export async function POST(req: NextRequest) {
  const body = await req.json();
  const parsed = schema.safeParse(body);
  if (!parsed.success) return NextResponse.json({ error: 'Dados inválidos' }, { status: 400 });

  const { name, email, password } = parsed.data;

  const existing = await prisma.user.findUnique({ where: { email } });
  if (existing) return NextResponse.json({ error: 'Email já cadastrado' }, { status: 409 });

  const passwordHash = await bcrypt.hash(password, 12);
  const user = await prisma.user.create({ data: { name, email, passwordHash } });

  return NextResponse.json({ id: user.id, name: user.name, email: user.email }, { status: 201 });
}
```
