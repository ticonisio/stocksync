## Story
**As a** lojista,
**I want** conectar minha loja Shopify ao StockSync inserindo meu token de API,
**so that** o sistema possa acessar meu inventário e manter o estoque sincronizado.

## Acceptance Criteria
1. Após primeiro login (Google OAuth ou credenciais), usuário sem loja conectada é redirecionado para `/onboarding/connect-shopify`
2. Formulário solicita: URL da loja (ex: `minha-loja.myshopify.com`) e Access Token da Custom/Private App
3. Ao submeter, sistema valida o token via chamada real à Shopify Admin API (`GET /admin/api/2024-01/shop.json`)
4. Token válido: salvo criptografado (AES-256-GCM) no banco via campo `accessTokenEncrypted` do modelo `Store`
5. Token inválido: mensagem de erro clara exibida com link para documentação da Shopify
6. Após conexão bem-sucedida, usuário redirecionado para `/onboarding/syncing`
7. Usuário pode reconectar ou trocar token em Configurações → Integração Shopify (apenas placeholder nesta story)

### Utilitário de Criptografia
[Source: `docs/architecture.md` Section 3 — Tech Stack]

```typescript
// src/lib/encrypt.ts
import crypto from 'crypto';

const ALGORITHM = 'aes-256-gcm';
const KEY_BYTES = 32;
const IV_BYTES = 12;

function getKey(): Buffer {
  const key = process.env.ENCRYPTION_KEY;
  if (!key) throw new Error('ENCRYPTION_KEY env var is required');
  const buf = Buffer.from(key, 'hex');
  if (buf.length !== KEY_BYTES) throw new Error('ENCRYPTION_KEY must be 32 bytes (64 hex chars)');
  return buf;
}

export function encrypt(text: string): string {
  const iv = crypto.randomBytes(IV_BYTES);
  const cipher = crypto.createCipheriv(ALGORITHM, getKey(), iv);
  const encrypted = Buffer.concat([cipher.update(text, 'utf8'), cipher.final()]);
  const authTag = cipher.getAuthTag();
  return `${iv.toString('hex')}:${authTag.toString('hex')}:${encrypted.toString('hex')}`;
}

export function decrypt(encryptedData: string): string {
  const [ivHex, authTagHex, ciphertextHex] = encryptedData.split(':');
  const iv = Buffer.from(ivHex, 'hex');
  const authTag = Buffer.from(authTagHex, 'hex');
  const ciphertext = Buffer.from(ciphertextHex, 'hex');
  const decipher = crypto.createDecipheriv(ALGORITHM, getKey(), iv);
  decipher.setAuthTag(authTag);
  return Buffer.concat([decipher.update(ciphertext), decipher.final()]).toString('utf8');
}
```

### API Route: POST /api/shopify/connect
[Source: `docs/architecture.md` Section 5 — API Specification]

```typescript
// src/app/api/shopify/connect/route.ts
import { NextResponse } from 'next/server';
import { getServerSession } from 'next-auth';
import { authOptions } from '@/lib/auth';
import { prisma } from '@/lib/prisma';
import { encrypt } from '@/lib/encrypt';
import { z } from 'zod';

const schema = z.object({
  shopifyDomain: z.string().min(1).transform(d =>
    d.replace(/^https?:\/\//, '').replace(/\/$/, '')
  ),
  accessToken: z.string().min(1),
});

export async function POST(req: Request) {
  const session = await getServerSession(authOptions);
  if (!session?.user?.id) return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });

  const body = await req.json();
  const parsed = schema.safeParse(body);
  if (!parsed.success) return NextResponse.json({ error: 'Invalid input' }, { status: 400 });

  const { shopifyDomain, accessToken } = parsed.data;

  // Validate token against Shopify Admin API
  let shopifyRes: Response;
  try {
    shopifyRes = await fetch(
      `https://${shopifyDomain}/admin/api/2024-01/shop.json`,
      {
        headers: { 'X-Shopify-Access-Token': accessToken },
        signal: AbortSignal.timeout(10000), // 10s timeout
      }
    );
  } catch {
    return NextResponse.json(
      { error: 'Não foi possível conectar à loja. Verifique o domínio informado.' },
      { status: 400 }
    );
  }

  if (!shopifyRes.ok) {
    return NextResponse.json(
      { error: 'Token ou domínio inválido. Verifique as credenciais da Custom App.' },
      { status: 400 }
    );
  }

  const store = await prisma.store.upsert({
    where: { userId_shopifyDomain: { userId: session.user.id, shopifyDomain } },
    update: { accessTokenEncrypted: encrypt(accessToken), syncStatus: 'PENDING' },
    create: {
      userId: session.user.id,
      shopifyDomain,
      accessTokenEncrypted: encrypt(accessToken),
      syncStatus: 'PENDING',
      webhooksRegistered: false,
    },
  });

  return NextResponse.json({ store: { id: store.id, shopifyDomain: store.shopifyDomain, syncStatus: store.syncStatus } });
}
```

### Normalização do Domínio Shopify
O campo `shopifyDomain` deve armazenar apenas o hostname: `minha-loja.myshopify.com`, sem `https://` ou trailing slash. A normalização acontece no Zod schema do backend.

### Variável de Ambiente Necessária
```env
# Gerar com: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
ENCRYPTION_KEY="64-hex-chars-aqui"
```
Adicionar também no Vercel (Settings → Environment Variables).

### Constraint do Schema Prisma
O modelo `Store` já existe no schema com a constraint `@@unique([userId, shopifyDomain])`. O `prisma.store.upsert` usa `userId_shopifyDomain` como chave de lookup. Não é necessária nenhuma migração adicional.
