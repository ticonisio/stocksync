## Story
**As a** lojista,
**I want** ver quais produtos estão vendendo mais rápido e quais valem a pena repor,
**so that** eu possa tomar decisões de recompra baseadas em dados de velocity reais, sem precisar analisar cada produto manualmente.

## Acceptance Criteria
1. Aba "Insights" acessível via navegação lateral (já existe no sidebar — esta story implementa o conteúdo)
2. Seção **Produtos em Alta:** top 10 produtos ordenados por velocity decrescente no período selecionado (rollup por produto = soma das velocities das variantes)
3. Card de Produto em Alta exibe: rank, nome, velocity total (un/dia), estoque disponível total, variante mais vendida (maior velocity individual)
4. Seção **Vale Repor:** produtos com velocity > 0 E estoque disponível total < velocity_produto × 14 dias
5. Card "Vale Repor" exibe: nome, estoque disponível total, dias restantes estimados (`Math.floor(totalAvailableStock / velocityPerDay)`), velocity total
6. Selector de período (7d / 30d / 90d) — padrão `30d` — aplica a ambas as seções; estado persistido em URL (`?period=`)
7. Estado vazio amigável quando sem dados de velocity: "Dados insuficientes — a velocity será calculada após os primeiros pedidos processados."

### Pattern de Agregação JS (insightsAggregator)

```typescript
// src/lib/insightsAggregator.ts

export interface ProductVelocityRollup {
  productId: string;
  title: string;
  velocityPerDay: number;
  totalAvailableStock: number;
  topVariantTitle: string;
}

type SalesVelocityWithVariant = {
  velocityPerDay: number;
  variant: {
    productId: string;
    title: string;
    availableStock: number;
    product: { title: string };
  };
};

export function aggregateVelocityByProduct(
  velocities: SalesVelocityWithVariant[]
): ProductVelocityRollup[] {
  const map = new Map<
    string,
    ProductVelocityRollup & { topVelocity: number }
  >();

  for (const sv of velocities) {
    const { productId, title: variantTitle, availableStock, product } = sv.variant;
    const existing = map.get(productId);

    if (!existing) {
      map.set(productId, {
        productId,
        title: product.title,
        velocityPerDay: sv.velocityPerDay,
        totalAvailableStock: availableStock,
        topVariantTitle: variantTitle,
        topVelocity: sv.velocityPerDay,
      });
    } else {
      existing.velocityPerDay += sv.velocityPerDay;
      existing.totalAvailableStock += availableStock;
      if (sv.velocityPerDay > existing.topVelocity) {
        existing.topVelocity = sv.velocityPerDay;
        existing.topVariantTitle = variantTitle;
      }
    }
  }

  return Array.from(map.values()).map(({ topVelocity: _top, ...rest }) => rest);
}
```

### Período — Validação

```typescript
const VALID_PERIODS = ['7d', '30d', '90d'] as const;
type Period = (typeof VALID_PERIODS)[number];

function parsePeriod(raw: string | undefined): Period {
  if (VALID_PERIODS.includes(raw as Period)) return raw as Period;
  return '30d'; // default
}
```
