## Story
**As a** lojista,
**I want** ver todos os meus produtos e variantes com seus níveis de estoque em uma única tela,
**so that** eu possa entender o estado completo do meu inventário em menos de 10 segundos.

## Acceptance Criteria
1. `/dashboard` exibe tabela paginada com todos os produtos sincronizados da store do usuário
2. Cada produto mostra rollup: nome, estoque disponível (soma variantes), reservado, comprometido
3. Produto expansível via clique para ver breakdown por variante (título, SKU, disponível, reservado, comprometido)
4. Estoque zero em todas as variantes exibe badge "Esgotado" na linha do produto
5. Paginação de 25 produtos por página com controles anterior/próximo e indicador de total
6. Carregamento inicial em ≤ 2s para lojas com até 500 produtos (Server Component com Prisma direto)
7. Estado vazio amigável quando nenhum produto sincronizado (com link para `/onboarding/connect-shopify`)

### Query Prisma para Dashboard
[Source: `docs/architecture.md` Section 4.3/4.4]

```typescript
// src/app/(dashboard)/dashboard/page.tsx
import { prisma } from '@/lib/prisma';
import { getServerSession } from 'next-auth';
import { authOptions } from '@/lib/auth';
import { redirect } from 'next/navigation';

const ITEMS_PER_PAGE = 25;

export default async function DashboardPage({
  searchParams,
}: {
  searchParams: { page?: string };
}) {
  const session = await getServerSession(authOptions);
  if (!session) redirect('/login');

  const store = await prisma.store.findFirst({ where: { userId: session.user.id } });
  if (!store) redirect('/onboarding/connect-shopify');

  const page = Math.max(1, parseInt(searchParams.page ?? '1', 10));
  const skip = (page - 1) * ITEMS_PER_PAGE;

  const [products, total] = await prisma.$transaction([
    prisma.product.findMany({
      where: { storeId: store.id },
      include: { variants: true },
      skip,
      take: ITEMS_PER_PAGE,
      orderBy: { title: 'asc' },
    }),
    prisma.product.count({ where: { storeId: store.id } }),
  ]);

  return <InventoryTable products={products} total={total} page={page} perPage={ITEMS_PER_PAGE} />;
}
```

### Cálculo de Rollup por Produto

```typescript
function calcRollup(variants: Variant[]) {
  return variants.reduce(
    (acc, v) => ({
      availableRollup: acc.availableRollup + v.availableStock,
      reservedRollup: acc.reservedRollup + v.reservedStock,
      committedRollup: acc.committedRollup + v.committedStock,
    }),
    { availableRollup: 0, reservedRollup: 0, committedRollup: 0 }
  );
}
```
