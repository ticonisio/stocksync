## Story
**As a** lojista,
**I want** visualizar o estoque de uma coleção específica diretamente na sidebar,
**so that** eu possa analisar o inventário por categoria sem sair do dashboard.

## Acceptance Criteria
1. Sidebar lista todas as coleções sincronizadas da Shopify, com contagem de produtos por coleção
2. Selecionar uma coleção filtra a tabela para mostrar apenas produtos daquela coleção (URL: `?collectionId=...`)
3. Item "Todos os Produtos" na sidebar retorna à visualização completa (sem filtro de coleção)
4. Dentro da view de coleção, ordenação adicional disponível: Maior estoque, Menor estoque, Mais vendidos (velocity), Urgência de recompra
5. Header da tabela exibe nome da coleção selecionada e contagem de produtos
6. Produtos sem nenhuma coleção agrupados em "Sem coleção" na sidebar (com contagem)
7. Filtros de busca e status (Story 3.3) funcionam dentro da view de coleção

## Dev Notes

### Tech Stack Relevante
- **Prisma `_count`:** contar produtos por coleção em uma única query
- **SWR 2.x:** fetch de coleções no cliente com cache automático
- **shadcn/ui:** `ScrollArea` para lista de coleções com overflow

### Query Coleções com Count
```typescript
// src/app/api/collections/route.ts
const collections = await prisma.collection.findMany({
  where: { storeId: store.id },
  include: { _count: { select: { products: true } } },
  orderBy: { title: 'asc' },
});

const uncategorizedCount = await prisma.product.count({
  where: { storeId: store.id, collections: { none: {} } },
});
```

### Filtro por Coleção na Query de Inventário
```typescript
// Adição ao where de GET /api/inventory
const collectionFilter: Prisma.ProductWhereInput = collectionId === 'uncategorized'
  ? { collections: { none: {} } }
  : collectionId
    ? { collections: { some: { id: collectionId, storeId: store.id } } }
    : {};
```

### Ordenação por Velocity
Para `sort=velocity`, é necessário join com `SalesVelocity`:
```typescript
// Abordagem: buscar products normalmente + sort em memória para MVP
// (performance adequada para ≤ 500 produtos por coleção)
const sorted = products.sort((a, b) => {
  const velA = getProductVelocity(a, salesVelocities, period);
  const velB = getProductVelocity(b, salesVelocities, period);
  return order === 'desc' ? velB - velA : velA - velB;
});
```

### Decisões de Arquitetura (não reabrir)
- `collectionId` na URL garante filtro navegável e compartilhável
- `collectionId = 'uncategorized'` como string especial para produtos sem coleção
- Sort por velocity em memória para MVP (sem subquery complexa) — adequado para ≤ 500 produtos/coleção
- Coleções buscadas via SWR no cliente — lista estável, cache evita refetch desnecessário
