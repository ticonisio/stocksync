## Story
**As a** lojista,
**I want** acessar uma página de detalhe de um produto,
**so that** eu possa ver o breakdown completo por variante, entender a velocity de vendas e configurar o lead time diretamente.

## Acceptance Criteria
1. Clicar em produto no dashboard abre `/products/[id]` com dados completos do produto
2. Exibe todas as variantes com: título, SKU, estoque disponível, reservado, comprometido
3. Velocity por variante exibida no período selecionado (7d / 30d / 90d) via selector
4. Campo inline de lead time individual por variante — salva com um clique (override do grupo)
5. Grupo de lead time atual do produto exibido com nome e prazo, com link para Configurações
6. Últimos 10 eventos de pedido que afetaram este produto (data, evento, variante, qtd)
7. Botão "Voltar" retorna para o dashboard preservando filtros ativos na URL

### Query Produto Completo
```typescript
// src/app/api/inventory/[productId]/route.ts
// ATENÇÃO: Relações corretas do schema Prisma:
// - Variant.salesVelocities (plural, não salesVelocity)
// - Product.collections → ProductCollection[] (junction) → collection: Collection
// - Product.leadTimeGroups → ProductLeadTimeGroup[] (junction) → leadTimeGroup: LeadTimeGroup
// - orderItems está em Variant, não em Product — buscar separado

const period = (searchParams.get('period') ?? '30d') as '7d' | '30d' | '90d';

const product = await prisma.product.findFirst({
  where: { id: productId, storeId: store.id },
  include: {
    variants: {
      include: {
        salesVelocities: {
          where: { period },
        },
      },
    },
    collections: {
      include: { collection: { select: { id: true, title: true } } },
    },
    leadTimeGroups: {
      include: { leadTimeGroup: { select: { id: true, name: true, leadTimeDays: true } } },
    },
  },
});

// Últimos 10 eventos via OrderItem
// orderItems é relação de Variant, não de Product — query separada necessária
const recentEvents = await prisma.orderItem.findMany({
  where: {
    variant: { productId, storeId: store.id },
  },
  include: {
    order: { select: { shopifyOrderId: true, status: true, createdAt: true } },
    variant: { select: { title: true, sku: true } },
  },
  orderBy: { order: { createdAt: 'desc' } },
  take: 10,
});
```

### PATCH Lead Time Override
```typescript
// src/app/api/products/[productId]/lead-time/route.ts
// ATENÇÃO: campo correto no schema é `leadTimeOverride` (Int?), não `leadTimeOverrideDays`
const schema = z.object({
  leadTimeOverride: z.number().int().positive().nullable(),
});

export async function PATCH(req: Request, { params }: { params: { productId: string } }) {
  const session = await getServerSession(authOptions);
  if (!session?.user?.id) return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });

  const store = await prisma.store.findFirst({ where: { userId: session.user.id } });
  const body = schema.safeParse(await req.json());
  if (!body.success) return NextResponse.json({ error: 'Invalid input' }, { status: 400 });

  const product = await prisma.product.updateMany({
    where: { id: params.productId, storeId: store!.id },
    data: { leadTimeOverride: body.data.leadTimeOverride },
  });

  if (product.count === 0) return NextResponse.json({ error: 'Not found' }, { status: 404 });
  return NextResponse.json({ ok: true });
}
```

```typescript
function formatVelocity(vel: number): string {
  if (vel === 0) return '—';
  if (vel < 0.1) return '< 0.1 un/dia';
  return `${vel.toFixed(2)} un/dia`;
}
```
