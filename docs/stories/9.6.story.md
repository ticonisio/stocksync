## Story
**As a** lojista,
**I want** uma aba "Pedidos" no menu lateral que liste todos os pedidos da minha loja com atualização em tempo real,
**so that** eu acompanhe as vendas assim que elas acontecem sem precisar alternar para o admin do Shopify.

## Acceptance Criteria
1. Nova entrada **"Pedidos"** no menu lateral (Sidebar) entre "Importações" e "Configurações", com ícone `ShoppingCart` (lucide-react)
2. Página `/orders` exibe uma tabela com todos os pedidos da loja, ordenados por data (mais recente primeiro)
3. Cada linha da tabela exibe: **Pedido** (shopifyOrderId), **Status** (badge colorido: PAID=verde, CANCELLED=vermelho, REFUNDED=amarelo, PENDING=cinza), **Itens** (quantidade total de itens), **Produtos** (nomes dos produtos/variantes), **Data** (createdAt formatado pt-BR)
4. Ao expandir uma linha, exibe os `OrderItem`s: nome da variante, SKU, quantidade
5. Paginação server-side com 25 itens por página (mesmo padrão do dashboard)
6. Filtro por **status** (Todos, Pagos, Cancelados, Reembolsados) via query param `?status=`
7. **Busca** por shopifyOrderId ou nome de produto/variante via query param `?search=`
8. **Real-time**: quando um novo pedido chega via webhook, a tabela atualiza automaticamente (nova linha aparece no topo com highlight de 2s) — via Supabase Realtime na tabela `Order`
9. **Real-time**: quando o status de um pedido muda (cancelled/refunded), o badge atualiza automaticamente
10. Badge no sidebar mostrando a contagem de pedidos das últimas 24h (ao lado do label "Pedidos")
11. Proteção cross-store mantida: dados filtrados pelo `storeId` do usuário autenticado

## Scope
### IN
- Página `/orders` (Server Component com Client Components para realtime)
- API route `/api/orders` para listagem paginada com filtros
- Hook `useOrdersRealtime` para Supabase Realtime na tabela `Order`
- Componentes: `OrdersTable`, `OrderStatusBadge`, `OrderFilters`
- Link no Sidebar com badge de contagem 24h
- Linhas expansíveis mostrando OrderItems

### OUT
- Criação/edição manual de pedidos (pedidos só entram via webhook)
- Detalhes financeiros (preço, total, impostos — não armazenados no schema atual)
- Integração com fulfillment (não há campo de fulfillment no schema)
- Adicionar campos ao schema Order (usar o que já existe)
- Exportação CSV de pedidos

## Technical Notes
- O schema `Order` já existe com: `id, storeId, shopifyOrderId, status (enum), items[], createdAt, updatedAt`
- O schema `OrderItem` já existe com: `id, orderId, variantId, quantity` + relation para `Variant` (que tem `title`, `sku`)
- O webhook `orders/paid` já cria o Order e OrderItems — a página só precisa LER
- Para realtime, usar Supabase `postgres_changes` na tabela `Order` (INSERT para novos, UPDATE para status change)
- O padrão de realtime já existe em `useInventoryRealtime.ts` — seguir o mesmo pattern
- Badge 24h: contar orders com `createdAt >= now() - 24h` no server, atualizar via realtime no client

## Dependencies
- Story 9.1 (Done) — padrão de badge no sidebar
- Webhooks de pedidos já funcionais (orders/paid, orders/cancelled, orders/refunded)
