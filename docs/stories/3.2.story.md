## Story
**As a** lojista,
**I want** que o dashboard atualize automaticamente quando um pedido entra ou muda de status,
**so that** eu sempre veja o estoque real sem precisar recarregar a página.

## Acceptance Criteria
1. Dashboard se inscreve no canal Supabase Realtime ao montar, desinscreve ao desmontar
2. Quando variante atualizada no banco (via webhook), linha do produto/variante atualiza em ≤ 5s sem reload
3. Atualização não intrusiva — sem piscar ou perder posição de scroll
4. Linha atualizada recebe highlight temporário (2s) para indicar mudança
5. Reconexão automática se canal Realtime cair, com toast discreto "Reconectando..."
6. Re-fetch via `GET /api/inventory` ao reconectar para garantir estado consistente
7. Zustand store gerencia estado de inventário para sincronização entre componentes

### Hook useInventoryRealtime
```typescript
// src/hooks/useInventoryRealtime.ts
import { useEffect } from 'react';
import { supabase } from '@/lib/supabase';
import { useInventoryStore } from '@/store/inventoryStore';
import { toast } from 'sonner';

export function useInventoryRealtime(storeId: string) {
  const { updateVariant, markUpdated } = useInventoryStore();

  useEffect(() => {
    const channel = supabase
      .channel(`inventory:${storeId}`)
      .on(
        'postgres_changes',
        { event: 'UPDATE', schema: 'public', table: 'variants', filter: `storeId=eq.${storeId}` },
        (payload) => {
          const v = payload.new as { id: string; availableStock: number; reservedStock: number; committedStock: number };
          updateVariant(v.id, {
            availableStock: v.availableStock,
            reservedStock: v.reservedStock,
            committedStock: v.committedStock,
          });
          markUpdated(v.id);
          setTimeout(() => useInventoryStore.getState().clearUpdated(v.id), 2000);
        }
      )
      .subscribe((status) => {
        if (status === 'CHANNEL_ERROR' || status === 'CLOSED') {
          toast.error('Conexão perdida. Reconectando...');
        }
      });

    return () => { void channel.unsubscribe(); };
  }, [storeId, updateVariant, markUpdated]);
}
```

### Zustand Store
```typescript
// src/store/inventoryStore.ts
import { create } from 'zustand';
import type { ProductWithVariants } from '@/types/inventory';

interface InventoryState {
  products: ProductWithVariants[];
  total: number;
  updatedVariantIds: Set<string>;
  setProducts: (products: ProductWithVariants[], total: number) => void;
  updateVariant: (variantId: string, patch: Partial<VariantWithStock>) => void;
  markUpdated: (variantId: string) => void;
  clearUpdated: (variantId: string) => void;
}

export const useInventoryStore = create<InventoryState>((set) => ({
  products: [],
  total: 0,
  updatedVariantIds: new Set(),
  setProducts: (products, total) => set({ products, total }),
  updateVariant: (variantId, patch) =>
    set((state) => ({
      products: state.products.map((p) => ({
        ...p,
        variants: p.variants.map((v) => v.id === variantId ? { ...v, ...patch } : v),
      })),
    })),
  markUpdated: (variantId) =>
    set((state) => ({ updatedVariantIds: new Set([...state.updatedVariantIds, variantId]) })),
  clearUpdated: (variantId) =>
    set((state) => {
      const next = new Set(state.updatedVariantIds);
      next.delete(variantId);
      return { updatedVariantIds: next };
    }),
}));
```

### Dependências a Instalar
```bash
npm install @supabase/supabase-js zustand swr sonner
```

### Decisões de Arquitetura (não reabrir)
- Supabase Realtime via Postgres CDC — zero infraestrutura adicional no servidor (arquitetura docs)
- Zustand (não Context) para estado de inventário — evita re-renders em árvore grande
- Re-fetch ao reconectar via SWR garante que estado está consistente após downtime
- `storeId` como filtro no canal Realtime — usuário só recebe atualizações da própria loja
