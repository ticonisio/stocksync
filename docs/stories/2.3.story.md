## Story
**As a** lojista,
**I want** ver todos os meus produtos, variantes e estoque disponível no dashboard,
**so that** eu possa monitorar meu inventário de forma centralizada após a sincronização com a Shopify.

## Acceptance Criteria
1. Dashboard (`/dashboard`) exibe lista de produtos com suas variantes e estoque disponível (`availableStock`)
2. Cada produto exibe: título, número de variantes e estoque total do produto (soma de `availableStock` de todas as variantes)
3. Cada variante exibe: título, SKU (ou "—" se null) e `availableStock`
4. Filtro por coleção via URL search param (`?collection={id}`): quando selecionado, exibe apenas produtos daquela coleção
5. Dropdown/select com lista de coleções da loja para selecionar o filtro (opção "Todas as coleções" por padrão)
6. Cards de resumo no topo: total de produtos, total de variantes, total de unidades em estoque
7. Estado vazio: se não há produtos sincronizados, exibe mensagem "Nenhum produto sincronizado ainda" com botão "Sincronizar agora" que redireciona para `/onboarding/syncing`
8. Dados carregados server-side via Prisma (Server Component) — sem loading spinner ou fetch no client

## Dev Notes

### Arquitetura: Server Component + Prisma direto

O dashboard usa o padrão já estabelecido no projeto (ver `layout.tsx` do dashboard):

```typescript
// src/app/(dashboard)/dashboard/page.tsx
import { getServerSession } from 'next-auth';
import { redirect } from 'next/navigation';
import { authOptions } from '@/lib/auth';
import { prisma } from '@/lib/prisma';

export default async function DashboardPage({
  searchParams,
}: {
  searchParams: { collection?: string };
}) {
  const session = await getServerSession(authOptions);
  if (!session) redirect('/login');

  const store = await prisma.store.findFirst({ where: { userId: session.user.id } });
  if (!store) redirect('/onboarding/connect-shopify');

  // ...buscar produtos com filtro
}
```

### Query Prisma com filtro opcional por coleção

```typescript
const products = await prisma.product.findMany({
  where: {
    storeId: store.id,
    ...(searchParams.collection
      ? {
          collections: {
            some: { collectionId: searchParams.collection },
          },
        }
      : {}),
  },
  include: {
    variants: true,
    collections: { include: { collection: true } },
  },
  orderBy: { title: 'asc' },
});
```

### Query de coleções (para o dropdown)

```typescript
const collections = await prisma.collection.findMany({
  where: { storeId: store.id },
  orderBy: { title: 'asc' },
  select: { id: true, title: true },
});
```

### Filtro por coleção via form GET (sem JS)

```tsx
<form method="GET">
  <select name="collection" onChange="this.form.submit()">
    <option value="">Todas as coleções</option>
    {collections.map((c) => (
      <option key={c.id} value={c.id} selected={searchParams.collection === c.id}>
        {c.title}
      </option>
    ))}
  </select>
</form>
```

> **Nota:** `onChange="this.form.submit()"` é inline JS — alternativa sem JS: botão de submit. Para MVP, usar Client Component mínimo só para o select (ver subtask 2.4).

### Alternativa Client Component para o select

Extrair apenas o dropdown em um componente client separado para usar `useRouter`:

```typescript
// src/components/inventory/CollectionFilter.tsx
'use client';
import { useRouter, useSearchParams } from 'next/navigation';

export function CollectionFilter({ collections, selected }: Props) {
  const router = useRouter();
  return (
    <select
      value={selected ?? ''}
      onChange={(e) => router.push(e.target.value ? `?collection=${e.target.value}` : '/dashboard')}
    >
      ...
    </select>
  );
}
```

### Badge de estoque (colorido)

```tsx
function StockBadge({ stock }: { stock: number }) {
  const color =
    stock >= 10 ? 'bg-green-100 text-green-800' :
    stock > 0  ? 'bg-yellow-100 text-yellow-800' :
                 'bg-red-100 text-red-800';
  return <span className={`px-2 py-0.5 rounded text-xs font-medium ${color}`}>{stock}</span>;
}
```

### Campos disponíveis no schema (confirmados)
- `Product`: `id`, `title`, `handle`, `variants[]`, `collections[]` (via ProductCollection)
- `Variant`: `id`, `title`, `sku`, `availableStock`, `reservedStock`, `committedStock`
- `Collection`: `id`, `title`, `handle`
- `ProductCollection`: `productId`, `collectionId` (@@id composto)

### Decisões de arquitetura (não reabrir)
- Dados carregados server-side via Prisma direto (sem API route de inventário) — mais simples para Server Component
- Filtro de coleção via URL search param (`?collection=`) — stateless, compatível com SSR
- Dropdown em Client Component separado (`CollectionFilter`) para UX sem page reload completo
- Sem paginação nesta story — MVP com `findMany` simples; paginação entra em story futura se necessário
