## Story
**As a** lojista,
**I want** ver o custo médio de cada produto, o valor total em estoque e o valor por produto diretamente no dashboard,
**so that** eu saiba quanto dinheiro tenho investido em inventário e possa tomar decisões de recompra informadas pelo custo.

## Acceptance Criteria
1. Novo card de resumo **"Valor em Estoque"** ao lado dos 4 cards existentes (Produtos, Variantes, Disponível, Reservado) exibindo o valor total: `Σ(availableStock × averageCost)` para todas as variantes com `averageCost` preenchido — formatado em BRL (`R$ X.XXX,XX`)
2. Se **nenhuma variante** possui `averageCost` (nenhuma importação feita), o card exibe "—" com tooltip "Importe uma planilha para calcular custos"
3. Na **tabela de inventário** (InventoryTable), nova coluna **"Custo Médio"** após "Comprometido" exibindo o custo médio ponderado do produto: `Σ(variant.availableStock × variant.averageCost) / Σ(variant.availableStock)` — formatado em BRL
4. Produtos/variantes **sem `averageCost`** exibem "—" na coluna de custo (não R$ 0)
5. Nas **linhas expandidas de variantes**, a coluna "Custo Médio" exibe `variant.averageCost` individual formatado em BRL
6. Nova coluna **"Valor"** na tabela exibindo `availableStock × averageCost` por produto (rollup das variantes) — formatado em BRL
7. Variantes/produtos sem `averageCost` exibem "—" na coluna "Valor"
8. Novo **sort "Valor"** disponível quando dentro de uma coleção (mesmo padrão de velocity/urgency) — ordena por valor em estoque decrescente
9. Proteção cross-store mantida: dados filtrados pelo `storeId` do usuário autenticado (já garantido pelo fluxo existente)

## Dev Notes

### Dados existentes no schema
```prisma
model Variant {
  availableStock   Int      @default(0)
  reservedStock    Int      @default(0)
  committedStock   Int      @default(0)
  averageCost      Float?   // ← preenchido por importações (Story 9.3)
}
```

### Fórmula: Custo Médio do Produto (rollup)
```ts
// Só variantes com averageCost preenchido
const variantsWithCost = product.variants.filter(v => v.averageCost != null);
const costRollup = variantsWithCost.reduce(
  (sum, v) => sum + v.availableStock * v.averageCost!, 0
);
const avgCostRollup = variantsWithCost.reduce((s, v) => s + v.availableStock, 0) > 0
  ? costRollup / variantsWithCost.reduce((s, v) => s + v.availableStock, 0)
  : null;
```

### Fórmula: Valor Total em Estoque (card)
```ts
// Server-side aggregate para performance
const totalValue = await prisma.variant.aggregate({
  where: { storeId: store.id, averageCost: { not: null } },
  _sum: { /* não suporta expressão computed */ }
});
// Alternativa: raw query
const [{ total }] = await prisma.$queryRaw<[{ total: number | null }]>`
  SELECT SUM("availableStock" * "averageCost") as total
  FROM "Variant"
  WHERE "storeId" = ${store.id} AND "averageCost" IS NOT NULL
`;
```

### Formatação BRL
```ts
function formatBRL(value: number | null): string {
  if (value == null) return '—';
  return new Intl.NumberFormat('pt-BR', {
    style: 'currency',
    currency: 'BRL',
  }).format(value);
}
```
