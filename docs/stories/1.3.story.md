## Story
**As a** lojista,
**I want** logar com minha conta Google,
**so that** eu possa acessar o StockSync sem criar uma senha separada.

## Acceptance Criteria
1. Botão "Continuar com Google" visível nas páginas `/login` e `/register`
2. Fluxo OAuth Google cria conta automática se for primeiro acesso
3. Google autentica na conta existente se email já cadastrado
4. NextAuth.js Google provider configurado com `GOOGLE_CLIENT_ID` e `GOOGLE_CLIENT_SECRET`
5. Usuário redirecionado para `/dashboard` após autenticação bem-sucedida
6. Erros de OAuth exibem mensagem amigável (ex: "Erro ao autenticar com Google. Tente novamente.")
7. Callback URL configurada em Google Cloud Console: `{NEXTAUTH_URL}/api/auth/callback/google`

## Dev Notes

### Tech Stack Relevante
- **NextAuth.js**: 4.x — `GoogleProvider` from `next-auth/providers/google` (já incluído no pacote)
- **PrismaAdapter**: já instalado — lida automaticamente com criação de `Account` para OAuth users
- **shadcn/ui Button**: usar `variant="outline"` para o botão Google

### Configuração Google Console
[Source: `docs/architecture.md` Section 13]

Para desenvolvimento local:
1. Acessar [console.cloud.google.com](https://console.cloud.google.com)
2. APIs & Services → Credentials → Create OAuth 2.0 Client ID
3. Application type: Web application
4. Authorized redirect URIs:
   - `http://localhost:3000/api/auth/callback/google` (dev)
   - `https://stocksync-three.vercel.app/api/auth/callback/google` (prod)
5. Copiar Client ID e Client Secret para `.env` e Vercel

### Atualização de `auth.ts`
[Source: `docs/architecture.md` Section 11.4]

```typescript
// src/lib/auth.ts — adicionar GoogleProvider
import GoogleProvider from 'next-auth/providers/google';

export const authOptions: NextAuthOptions = {
  // ...providers existentes...
  providers: [
    CredentialsProvider({ /* já existente */ }),
    GoogleProvider({
      clientId: process.env.GOOGLE_CLIENT_ID!,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
    }),
  ],
  // ...callbacks existentes...
  pages: {
    signIn: '/login',
    newUser: '/onboarding/connect-shopify', // Story 1.4/2.1
  },
};
```

### Tratamento de Erros OAuth
NextAuth passa erros via `?error=OAuthSignin` na URL de redirect. As páginas devem ler `searchParams.error` e exibir mensagem amigável.

```typescript
// Exemplo em login/page.tsx
const errorMessage = searchParams?.error
  ? 'Erro ao autenticar com Google. Tente novamente.'
  : null;
```

### Variáveis de Ambiente Necessárias
```env
GOOGLE_CLIENT_ID="seu-client-id-aqui"
GOOGLE_CLIENT_SECRET="seu-client-secret-aqui"
```
Adicionar também no Vercel (Settings → Environment Variables).

### Fluxo OAuth com Usuário Existente
O `PrismaAdapter` trata automaticamente o caso de email já cadastrado:
- Se o email Google já existe como usuário Credentials: cria registro `Account` vinculado
- Se for novo email: cria novo `User` + `Account`

### Decisões de Arquitetura (não reabrir)
- `pages.newUser` aponta para `/onboarding/connect-shopify` — não criar esta página nesta story, apenas configurar o redirect
- Ícone Google: usar SVG inline simples (evitar dependência extra de pacote de ícones)
- `callbackUrl: '/dashboard'` explícito no `signIn()` para garantir redirect correto
